# SOCIAL GRAPH (소셜 그래프)

> 사회 교과서 속 그래프를 움직이다.

고등학교 사회 교과의 그래프와 도표를 학생과 교사가 직접 조작하며 탐구하는 인터랙티브 그래프 웹사이트예요.
서버, 데이터베이스, 로그인, AI API 없이 HTML·CSS·JavaScript만으로 작동해요.

## 들어 있는 그래프

| 그래프 | 관련 교과 | 핵심 기능 |
|---|---|---|
| 사회 계층 구조 | 사회와 문화 | 합계 100% 유지, 유형 자동 표시(피라미드형·다이아몬드형·역피라미드형·모래시계형·기타) |
| 사회 계층 이동표 | 사회와 문화 | 3×3 이동표, 상승·하강·유지 비율과 분모 표시, 생키 다이어그램 |
| 수요와 공급 곡선 | 경제 | 직선 모형, 균형가격·균형거래량을 교점 계산식으로 정확히 표시 |
| 인구 피라미드 | 통합사회, 지리 | 5세 단위 내부 자료로 유소년·생산연령·고령 인구 비율 계산 |
| 로렌츠 곡선과 지니계수 | 경제 | 5분위 점유율, 순서 검증, 면적으로 지니계수 계산 |
| 기후 그래프 | 통합사회, 지리 | 기온(꺾은선)·강수량(막대) 이중 축, 두 지역 비교 |
| 선거 제도와 의석 배분 | 정치 | 소선거구제 지역구 10석과 비례대표 10석 비교, 사표·불비례 정도, 봉쇄 조항, 여대야소·여소야대 |

모든 그래프에 공통으로 들어 있는 기능: 슬라이더와 숫자 입력, 실시간 변화, 변화 전후 비교, 예시, 초기화, PNG 저장, 전체 화면, 규칙 기반 자동 해석.

## 1. 내 컴퓨터에서 열어 보기

가장 쉬운 방법: `index.html`을 크롬이나 엣지에서 더블클릭해서 열어요.

> 글꼴(Pretendard)은 인터넷에서 불러와요. 인터넷이 없으면 컴퓨터의 기본 한글 글꼴로 보여요. 기능은 그대로 작동해요.

## 2. GitHub Pages로 배포하기 (처음 하는 분용)

1. [github.com](https://github.com)에 로그인하고, 오른쪽 위 **+** → **New repository**를 눌러요.
2. Repository name에 `social-graph`처럼 영어 이름을 쓰고 **Public**을 고른 뒤 **Create repository**를 눌러요.
3. 새 저장소 화면에서 **uploading an existing file** 링크를 눌러요.
4. 이 폴더 안의 파일 6개(`index.html`, `style.css`, `app.js`, `graphs.js`, `data.js`, `README.md`)를 끌어다 놓고, 아래 **Commit changes**를 눌러요.
   - 폴더째 올리지 말고 **파일들만** 올려야 해요. 저장소 첫 화면에 `index.html`이 바로 보여야 해요.
5. 저장소 위쪽 **Settings** → 왼쪽 메뉴 **Pages**로 가요.
6. **Build and deployment**에서 Source는 **Deploy from a branch**, Branch는 **main**과 **/(root)**를 고르고 **Save**를 눌러요.
7. 1~2분 뒤 새로고침하면 위쪽에 `https://내아이디.github.io/social-graph/` 주소가 나와요. 이 주소를 학생들에게 알려 주면 돼요.

모든 파일은 상대 경로로 연결되어 있고 화면 이동은 주소의 `#` 뒷부분(예: `#/graph/market`)을 쓰기 때문에, 위처럼 저장소 이름이 붙은 하위 경로에서도 그대로 작동해요. 특정 그래프로 바로 가는 링크도 만들 수 있어요. 예: `https://내아이디.github.io/social-graph/#/graph/lorenz`

**수정한 뒤 다시 배포하기**: 저장소에서 바꾼 파일을 다시 올리고(Add file → Upload files) Commit 하면, 1~2분 뒤 사이트에 반영돼요.

## 3. 파일 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 기본 뼈대. 글꼴과 아래 파일들을 불러와요 |
| `style.css` | 전체 디자인. 맨 위 `:root`의 색상 변수만 바꾸면 사이트 전체 색이 바뀌어요 |
| `data.js` | 그래프별 **초기값과 예시 숫자**, 자료 출처 정보, 과목 필터 목록 |

| `app.js` | 모든 그래프에 공통인 기능(화면 이동, 필터, 조절 패널, 비교, 예시, PNG, 전체 화면) |

## 4. 자주 하는 수정

### 예시 숫자 바꾸기
`data.js`에서 해당 그래프를 찾아 숫자만 바꾸면 돼요.

```js
// data.js - 사회 계층 구조의 '다이아몬드형' 예시
{ id: "diamond", label: "다이아몬드형", state: { upper: 15, middle: 65, lower: 20 } },
```

- 계층 구조: 세 값의 합이 100이 되게 써 주세요.
- 로렌츠 곡선: 다섯 값이 작은 것부터 큰 순서이고 합이 100이 되게 써 주세요.
- 인구 피라미드: 5세 단위 17개 값(0~4세 … 75~79세, 80세 이상), 단위는 천 명이에요.
- 선거 제도: 네 정당 득표율의 합이 100이 되게 써 주세요. 지역구 수와 지역별 지지율 차이는 `election.offsets`에서 바꿔요(각 행·열의 합이 0이어야 전국 득표율이 유지돼요).

### 예시 추가하기
같은 형식으로 한 줄을 더 넣으면 버튼이 자동으로 생겨요. `id`는 겹치지 않는 영어 이름으로 써 주세요.

### 색상 바꾸기
`style.css` 맨 위 `:root`에서 사이트 색을, `graphs.js` 맨 위 `const C = {...}`에서 그래프 색을 바꿔요.

### 실제 공공 통계 넣기
예시에 `source`를 붙이면 화면과 PNG에 출처가 표시되고, 학생이 그 값을 바꾸면 자동으로 **'원본 자료를 바꾼 가상 실험 결과'**로 표시돼요.

```js
{
  id: "kosis2024", label: "실제 자료 예시",
  state: { s: [ /* 실제 값 */ ] },
  source: {
    type: "real",
    name: "자료명",
    year: "조사 연도",
    org: "출처 기관",
    url: "https://출처-링크",
    unit: "단위"
  }
}
```

## 5. 새 그래프 추가하기

1. `data.js`의 `SG.data` 안에 새 그래프의 초기값과 예시를 넣어요.

```js
myGraph: {
  source: SG.VIRTUAL,
  initial: { a: 50 },
  presets: [
    { id: "low", label: "낮음", state: { a: 20 } },
    { id: "high", label: "높음", state: { a: 80 } }
  ]
},
```

2. `graphs.js` 맨 아래 `})();` 바로 위에 아래 틀을 붙여 넣고 내용을 바꿔요. 메인 화면 카드, 조절 패널, 비교, PNG, 전체 화면은 자동으로 붙어요.

```js
add({
  id: "myGraph",                       // data.js의 이름과 같아야 해요
  title: "새 그래프",
  subjects: ["politics"],              // integrated, sociology, economics, geography, politics
  summary: "카드에 보일 한 줄 설명",
  desc: "상세 화면 위쪽 설명",
  initial: () => u.clone(SG.data.myGraph.initial),
  controls: () => ({ groups: [{ title: "조절할 값", items: [
    { key: "a", label: "값 A", min: 0, max: 100, step: 1, unit: "%" }
  ] }] }),
  normalize: (s, key) => null,         // 합계 맞추기 등이 필요하면 여기서, 안내 문구를 return
  compute: (s) => ({ double: s.a * 2 }),
  draw: (s, r, base, br) => u.svg(760, 400,
    u.rect(80, 300 - s.a * 2.5, 120, s.a * 2.5, { fill: C.blue }) +
    (base ? u.rect(80, 300 - base.a * 2.5, 120, base.a * 2.5, { stroke: C.base, dash: "6 4" }) : "") +
    u.t(140, 330, "값 A", { anchor: "middle" })),
  legend: (s, r, base) => [{ label: "값 A", color: C.blue }].concat(base ? [{ label: "비교 기준", color: C.base, dash: true }] : []),
  metrics: (s, r) => [{ label: "값 A", value: s.a, digits: 0, unit: "%p" }],
  results: (s, r) => `<p class="result-line"><span>A × 2</span><b>${r.double}</b></p>`,
  interpret: (s, r, base) => [s.a >= 50 ? "A가 절반 이상이에요." : "A가 절반보다 적어요."],
  // [용어, 설명, 작은 그림(선택)] · 설명 속 <mark>…</mark>는 형광펜 강조 · 그림은 graphs.js의 FIG에 추가
  concept: K([["용어 1", "<mark>핵심 구절</mark>이 들어간 짧은 설명", FIG.laws], ["용어 2", "짧은 설명"]], "점선 상자에 들어갈 안내 (없으면 생략)"),
  howto: ["활용 방법 1", "활용 방법 2"],   // 이용 안내 > 그래프별 수업 활용 방법에 모여서 보여요
  preview: `<svg viewBox="0 0 200 120"><rect x="80" y="30" width="40" height="80" fill="${C.blue}"/></svg>`
});
```

- `metrics`의 `unit`을 `"%p"`로 쓰면 값은 %, 증감은 %p로 표시돼요.
- `draw`가 돌려주는 SVG는 그대로 PNG 저장에도 쓰여요. 색은 CSS가 아니라 SVG 속성으로 지정해야 PNG에 제대로 나와요.
- 조절할 칸이 많으면 `controls`에 `quick: { title, note, items: [{ key: "q.이름", ... }] }`을 더해요. 그러면 패널 위쪽에 **한 번에 조절** 슬라이더가 나오고, `groups`의 칸별 슬라이더는 **세부 조절** 버튼 안에 접혀요. `q.`로 시작하는 값은 그래프의 `get(s, key)`·`set(s, key, v)`로 읽고 써요(예: 인구 피라미드, 기후 그래프, 계층 이동표).

## 6. 계산 기준

- **계층 구조 유형**: 세 계층 사이 차이가 3%p 이상일 때만 크기 차이로 인정해요. 피라미드형(하 > 중 > 상), 역피라미드형(상 > 중 > 하), 다이아몬드형(중층이 가장 많음), 모래시계형(중층이 가장 적음), 그 밖에는 '기타 형태'예요.
- **계층 이동표**: 행 = 부모, 열 = 자녀. 대각선 = 유지, 자녀가 더 높은 계층 = 상승, 더 낮은 계층 = 하강. 기본 비율의 분모는 전체 인원이고, '부모 계층별 유지 비율'의 분모는 해당 부모 계층 인원이에요.
- **수요와 공급**: Qd = A − P, Qs = (B − 100) + P → P* = (A − B + 100) / 2, Q* = (A + B − 100) / 2. 가격 1단위 = 100원.
- **인구 지표**: 유소년 0~14세, 생산연령 15~64세, 고령 65세 이상. 부양비와 노령화 지수는 ×100. UN 기준 고령화 사회 7%, 고령 사회 14%, 초고령 사회 20%.
- **지니계수**: 5분위 점을 직선으로 이은 로렌츠 곡선 아래 면적 B를 사다리꼴로 구하고, 지니계수 = 1 − 2B. 같은 분위 안의 격차가 빠져 실제보다 작게 나오는 근사값이며, 이 방식의 최댓값은 0.8이에요.
- **기후 그래프**: 연평균 기온 = 12개월 평균, 연 강수량 = 12개월 합, 연교차 = 최난월 − 최한월. 기후 유형은 자동으로 판정하지 않아요.
- **한 번에 조절**: 인구 피라미드는 생산연령 인구를 고정하고 유소년(0~14세)·고령(65세 이상) 구간을 기존 모양대로 늘리거나 줄여 목표 비율을 맞춰요(두 비율의 합은 최대 90%). 기후 그래프는 연평균 기온 = 12개월을 같은 만큼 올리고 내림, 연교차 = 평균을 중심으로 늘이고 줄임, 연 강수량 = 기존 비율대로 나눔. 계층 이동표는 전체 인원을 고정하고 유지·상승·하강 칸을 기존 비율대로 나눠요. 값을 0으로 만들었다가 다시 올리면 원래 모양 대신 고르게 나뉜 모양으로 돌아와요.
- **선거 제도**: 지역구 득표율 = 전국 득표율 + 지역별 지지 차이 × 지역 편차(음수는 0으로 두고 합계 100%로 다시 맞춤), 지역구마다 1등 1명 당선(동률이면 앞 순서 정당). 비례대표는 봉쇄 조항을 넘은 정당끼리 최대 잔여 방식으로 나눠요. 사표 비율 = 지역구 낙선 득표율의 평균, 불비례 정도 = Σ|의석률 − 득표율| ÷ 2. 여당(대통령 소속 정당)이 전체 의석의 과반(20석 ÷ 2 + 1 = 11석 이상)이면 여대야소, 아니면 여소야대로 표시해요. 실제 국회의원 선거의 비례대표 배분 방식보다 단순화한 모형이에요.

## 7. 점검 결과

크롬 기반 브라우저에서, GitHub Pages처럼 하위 경로(`/social-graph/`)로 서버를 띄워 확인했어요.

**확인한 것**
- 7개 그래프 모두: 슬라이더와 숫자 입력이 서로 연동되고, 값을 바꾸면 그래프·계산 결과·해석이 바로 바뀜
- 계산 정확성: 각 그래프의 계산 결과를 손계산 또는 별도 계산과 비교해 일치 확인
  - 이동표 기본값: 500명, 상승 110명(22%), 하강 120명(24%), 유지 270명(54%)
  - 수요·공급: 그래프의 균형점이 두 직선 위에 정확히 놓이고(거리 0), 표시된 균형가격·균형거래량과 일치
  - 인구 피라미드: 세 예시의 유소년·고령 비율이 원자료 재계산값과 일치
  - 지니계수: 다섯 예시 모두 별도 계산값과 소수 셋째 자리까지 일치
  - 선거 제도 기본값(40·35·17·8%): 지역구 A당 6석·B당 4석, 비례대표 4·3·2·1석, 지역구 사표 55.7%, 불비례 정도 지역구 25%p·비례 5%p로 손계산과 일치. 봉쇄 조항 10%일 때 D당 제외 후 4·4·2석도 일치
- 잘못된 입력: 범위를 벗어난 값, 빈칸, 합계 100% 초과, 로렌츠 순서 위반 → 자동으로 맞추고 안내 문구 표시
- 예시, 초기화, 변화 전후 비교(점선 겹쳐 보기와 증감표)
- PNG 저장: 7개 그래프 모두 이미지 생성 확인(제목, 축 이름, 범례, 주요 수치, 자료 안내 포함)
